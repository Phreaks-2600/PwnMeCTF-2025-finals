# EmailBackend

## Description
You've been handed a messy, vulnerable email service.
Your mission:  
**Find and patch all backend vulnerabilities** — from forged tokens to insecure object access and more.
(Focus on the features and code which are present, no need to add extra security even if there could be more security.)

When you've fixed everything, run the tests. (connect to the nc server and all updates to your code will already be updated and used!)
If they all pass, you'll get the **flag**.

Good luck, dev detective. 🕵️‍♂️

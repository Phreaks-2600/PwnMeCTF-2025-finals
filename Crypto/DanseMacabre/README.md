# Danse Macabre

## Description
Enginners at *Danse Macabre* claim they have developed *The MAC* — a
blazing-fast, secure, rate-1 Message Authentication Code algorithm.
They claim this discovery is probably the biggest breakthrough in symmetric
cryptography, and they are pushing to make it the industry standard.

Sounds too good to be true? Time to prove them wrong.
Your task: Find a collision!
